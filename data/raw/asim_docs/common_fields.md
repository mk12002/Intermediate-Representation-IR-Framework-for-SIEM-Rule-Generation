## Standard Log Analytics fields

| Field | Type | Discussion |
| --- | --- | --- |
| **TimeGenerated** | Date/Time | The time the event was generated by the reporting device. |
| **Type** | String | The original table from which the record was fetched. |

## Common ASIM fields

### Event fields

| Field | Class | Type | Description |
| --- | --- | --- | --- |
| **EventMessage** | Optional | String | A general message. |
| **EventCount** | Mandatory | Integer | The number of events. |
| **EventStartTime** | Mandatory | Date/time | The time when the event started. |
| **EventEndTime** | Mandatory | Date/time | The time when the event ended. |
| **EventType** | Mandatory | Enumerated | Describes the operation reported by the record. |
| **EventSubType** | Optional | Enumerated | Describes a subdivision of the operation. |
| **EventResult** | Mandatory | Enumerated | Success, Partial, Failure, NA. |
| **EventResultDetails** | Recommended | Enumerated | Reason or details for the result. |
| **EventUid** | Recommended | String | The unique ID of the record. |
| **EventOriginalUid** | Optional | String | A unique ID of the original record. |
| **EventOriginalType** | Optional | String | The original event type or ID. |
| **EventOriginalSubType** | Optional | String | The original event subtype or ID. |
| **EventOriginalResultDetails** | Optional | String | The original result details. |
| **EventSeverity** | Recommended | Enumerated | Informational, Low, Medium, High. |
| **EventOriginalSeverity** | Optional | String | The original severity. |
| **EventProduct** | Mandatory | String | The product generating the event. |
| **EventProductVersion** | Optional | String | The version of the product. |
| **EventVendor** | Mandatory | String | The vendor of the product. |
| **EventSchema** | Mandatory | Enumerated | The schema the event is normalized to. |
| **EventSchemaVersion** | Mandatory | SchemaVersion (String) | The version of the schema. |
| **EventReportUrl** | Optional | URL (String) | A URL for more information about the event. |
| **EventOwner** | Optional | String | The owner of the event. |

### Device fields

| Field | Class | Type | Description |
| --- | --- | --- | --- |
| **Dvc** | Alias | String | A unique identifier of the device. |
| **DvcIpAddr** | Recommended | IP address | The IP address of the device. |
| **DvcHostname** | Recommended | Hostname | The hostname of the device. |
| **DvcDomain** | Recommended | Domain (String) | The domain of the device. |
| **DvcDomainType** | Conditional | Enumerated | The type of DvcDomain. |
| **DvcFQDN** | Optional | FQDN (String) | The hostname of the device, with domain. |
| **DvcDescription** | Optional | String | A descriptive text associated with the device. |
| **DvcId** | Optional | String | The unique ID of the device. |
| **DvcIdType** | Conditional | Enumerated | The type of DvcId. |
| **DvcMacAddr** | Optional | MAC address | The MAC address of the device. |
| **DvcZone** | Optional | String | The network zone of the device. |
| **DvcOs** | Optional | String | The operating system of the device. |
| **DvcOsVersion** | Optional | String | The OS version of the device. |
| **DvcAction** | Optional | String | The action taken by the reporting system. |
| **DvcOriginalAction** | Optional | String | The original DvcAction. |
| **DvcInterface** | Optional | String | The network interface on which data was captured. |
| **DvcScopeId** | Optional | String | The cloud platform scope ID. |
| **DvcScope** | Optional | String | The cloud platform scope. |

### Other fields

| Field | Class | Type | Description |
| --- | --- | --- | --- |
| **AdditionalFields** | Optional | Dynamic | Extra information as key/value pairs. |
